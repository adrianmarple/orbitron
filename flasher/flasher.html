Lumatron Arduino Flasher

This browser can't talk to USB devices.

Open this page in Chrome or Edge on a desktop computer. Safari and Firefox don't support WebSerial, and neither do phones or tablets.

This erases the arduino controller completely. Lighting settings, saved presets, timers and the saved WiFi network are all wiped. Afterwards the orb needs to be reconnected to WiFi and have its settings restored.
  1. Open the controller box.
  2. Plug the newly exposed USB-C port on the side into this computer with a USB cable.
  3. Click the button below and pick the orb from the list that appears, something like: "serial debug unit (cu.usbmodem101)".
  4. Leave it plugged in until it says done — about a minute.

Couldn't connect to the orb.

Some boards need to be put into flashing mode by hand:

  1. Hold down the BOOT button (sometimes labelled B).
  2. While holding it, press and release RESET (sometimes R).
  3. Let go of BOOT, then click the button above again.

If that doesn't help, try a different USB cable — some charge-only cables carry no data.

Done. The orb is restarting.

If its lights don't come back on within a few seconds, unplug the USB cable and plug it back in.

To finish setting it up:

  1. On your phone or laptop, join the WiFi network named Lumatron-arduino.
  2. A setup page should open by itself. Pick your WiFi network and enter its password.
  3. Restore the orb's settings from a backup in the admin page.
